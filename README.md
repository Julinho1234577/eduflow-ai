Plataforma inteligente de gestión educativa.

## Tecnologías

- React
- Laravel
- PHP
- PostgreSQL
- Python
- FastAPI
- Machine Learning
- Docker
- GitHub Actions

- Notas

Laravel → FastAPI → Machine Learning
